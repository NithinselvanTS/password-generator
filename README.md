\# password-generator



A small command-line password generator written in Python using the `secrets` module. Built as a starter project to practice Python scripting and Git workflows.



\## Usage



Run the script and enter the length you want:



```bash

python main.py

```



Example:

```text

Password length: 12

Generated password: x7#K9pL2$mQ4

```
